# Submission checklist

## Before sending any application

- [ ] Confirm the listing is still open.
- [ ] Confirm eligibility/location requirements.
- [ ] Confirm current availability and hours.
- [ ] Confirm requested rate/budget.
- [ ] Select 2-3 repository examples actually relevant to the listing.
- [ ] Run the demo and record only verified behavior.
- [ ] Remove secrets from all public artifacts.
- [ ] Do not claim earnings, clients, uptime, production deployment, or credentials that cannot be demonstrated.
- [ ] Human reviews and submits the final application.
